# Gallery photos folder

Add up to 6 photos here, named exactly:

```
photo-1.jpg
photo-2.jpg
photo-3.jpg
photo-4.jpg
photo-5.jpg
photo-6.jpg
```

Each gallery tile on the site tries to load its matching photo
automatically — you don't need to touch any code. Add them one
at a time, in any order; a tile without a matching file just
shows the elegant placeholder design instead.

Tip: photos roughly 800–1200px wide load fastest and still look
sharp on phones and laptops alike.
