# Music folder

Put your background music file here, named exactly:

```
wedding.mp3
```

So the final path is `assets/music/wedding.mp3`.

That's the only step — `index.html` already points to this path.
If you use a different filename, update the `<source src="...">`
line inside the `<audio>` tag near the bottom of `index.html` to match.

No file here yet? Nothing breaks — the music button on the site
just stays visible but does nothing until you add one.
